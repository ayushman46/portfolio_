# SEO handoff

The portfolio is configured with canonical metadata, JSON-LD identity data, crawlable public routes, `robots.txt`, `sitemap.xml`, and `llms.txt`.

After deployment:

1. Add `https://ayushmanchakraborty.vercel.app/` to Google Search Console and verify ownership.
2. Submit `https://ayushmanchakraborty.vercel.app/sitemap.xml`.
3. Request indexing for the homepage, `/work`, `/projects`, `/projects/codeglyph`, `/projects/prepvia`, and `/projects/releaselens`.
4. Add the site to Bing Webmaster Tools and submit the same sitemap.
5. Validate the homepage and project structured data with Google Rich Results Test and Schema Markup Validator.
6. Test `https://ayushmanchakraborty.vercel.app/robots.txt`, `/sitemap.xml`, and `/llms.txt` after deployment.
7. Add the portfolio URL to the website fields on the GitHub and LinkedIn profiles.
8. Where accurate, link the major GitHub repositories back to their matching portfolio project pages.

No Google or Bing verification token was added because none was available in the repository. No unverified social profiles, credentials, awards, testimonials, or fabricated project metrics were added.
